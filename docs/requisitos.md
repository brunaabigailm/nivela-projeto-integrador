# Requisitos do Sistema – NIVELA

## Descrição

Este documento apresenta os requisitos funcionais, requisitos não funcionais e regras de negócio do sistema NIVELA.

O objetivo é registrar as funcionalidades esperadas para o MVP acadêmico e orientar as próximas etapas de desenvolvimento da plataforma.

---

## Requisitos Funcionais

- RF01: O sistema deve permitir o cadastro de usuários.
- RF02: O sistema deve permitir o cadastro de colaboradores.
- RF03: O sistema deve permitir o cadastro de gestores.
- RF04: O sistema deve permitir o cadastro de cargos e áreas.
- RF05: O sistema deve permitir a criação de trilhas de onboarding.
- RF06: O sistema deve permitir a criação de módulos dentro das trilhas.
- RF07: O sistema deve permitir o cadastro de conteúdos de aprendizagem.
- RF08: O sistema deve permitir o cadastro de avaliações simples.
- RF09: O sistema deve permitir que o colaborador visualize suas trilhas atribuídas.
- RF10: O sistema deve permitir que o colaborador acesse conteúdos de aprendizagem.
- RF11: O sistema deve permitir que o colaborador responda avaliações.
- RF12: O sistema deve permitir que o gestor acompanhe o progresso dos colaboradores.
- RF13: O sistema deve exibir indicadores básicos de conclusão das trilhas.
- RF14: O sistema deve permitir a organização das informações por empresa, área e cargo.

---

## Requisitos Não Funcionais

- RNF01: O sistema deve possuir interface simples e intuitiva.
- RNF02: O sistema deve ser desenvolvido como uma aplicação web.
- RNF03: O sistema deve utilizar banco de dados relacional.
- RNF04: O sistema deve possuir estrutura organizada no GitHub.
- RNF05: O sistema deve ser compatível com navegadores modernos.
- RNF06: O sistema deve permitir futuras melhorias e integrações.
- RNF07: O sistema deve apresentar tempo de resposta adequado para as principais operações.
- RNF08: O sistema deve armazenar os dados de forma estruturada e consistente.

---

## Regras de Negócio

- RN01: Cada colaborador deve estar vinculado a uma empresa.
- RN02: Cada colaborador pode estar vinculado a uma área ou cargo.
- RN03: Uma trilha pode conter um ou mais módulos.
- RN04: Cada módulo pode conter um ou mais conteúdos.
- RN05: Uma trilha pode conter uma ou mais avaliações.
- RN06: O progresso do colaborador deve ser calculado com base nos conteúdos concluídos e avaliações realizadas.
- RN07: Apenas gestores ou administradores podem criar trilhas, conteúdos e avaliações.
- RN08: Colaboradores podem apenas visualizar e realizar as trilhas atribuídas a eles.

---

## Observação

Os requisitos poderão ser ajustados conforme a evolução do projeto e as orientações recebidas durante o desenvolvimento do Projeto Integrador.
